Quality Control Sign OCA

This module provides a seamless integration between the OCA Quality
Control module and the Sign OCA module. It allows companies to request
and collect digital signatures directly on the exported PDF report of a
quality inspection.

The goal is to streamline validation processes, ensure full
traceability, and centralize signed documents inside the inspection
record.

Configuration
=============

To configure the signature workflow for Quality Control inspections, go
to:

Settings → General Settings → Quality Control Sign

Go to: Sales → Configuration → Quanlity Control Signature Template Items

• Inspection Report for Signature

Select the PDF report of Quality Control Inspection that will be
generated and sent for signature. This report will be rendered as a PDF
and used as the base document for the signature request.

• Signature Roles

Define the parties required to sign the inspection report (e.g.,
Inspector, Supervisor, Customer). Each role corresponds to a signer and
controls who must sign the generated document.

• Signature Positions

Configure the fixed positions of signature fields on the selected PDF
report. For each report and role, you can specify:

Page number

X/Y coordinates

Width and height of the signature box

Whether the signature is required

These positions will be used to automatically generate the digital
signature template.
