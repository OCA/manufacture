Add a warehouse manufacturing configuration that consumes components
directly from Stock and produces finished goods in Post-Production. A
separate internal transfer stores the finished goods in Stock.

The storage transfer is created when manufacturing finishes, as in
Odoo's standard three-step manufacturing flow. It stays linked to the
manufacturing output and follows standard stock move reservation and
backorder behavior.

This module follows the routing proposed in `OCA/manufacture issue
#1883 <https://github.com/OCA/manufacture/issues/1883>`__, with the
transfer creation timing of Odoo's standard three-step flow.

Configuration
=============

In Inventory > Configuration > Warehouses, choose **Manufacture then
store products (2 steps)** under Manufacture.

The warehouse uses its existing Post-Production location, Manufacturing
operation type, and Store Finished Product operation type. Their
reservation settings remain configurable. Switching from three-step
manufacturing keeps stocked manufacturing locations active; it does not
move their products.

Usage
=====

Confirm a manufacturing order using the configured warehouse's
Manufacturing operation type. Components are reserved from Stock.
Complete the manufacturing order to create the Store Finished Product
transfer from Post-Production. Validate that transfer to move the
finished products into Stock.

If manufacturing is partial, a transfer is created for the quantity
already produced. Further output creates or updates a transfer when the
manufacturing backorder is completed.
