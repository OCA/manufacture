When a reason code has workcenters assigned and the scrap has a
workorder, an additional filter is added to allow only select reason
codes with the same workcenter as the workorder .

Configuration
=============

Go to Inventory > Configuration > Scrap Reason Codes

Create a required scrap reason code and assign work centers.
