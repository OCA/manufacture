- A lot/serial number keeps a single Bill of Materials: the one of the last
  done manufacturing order that produced it. For serial numbers this is
  exact, as a unit comes from a single manufacturing order. A lot, however,
  can be produced by several manufacturing orders with different Bills of
  Materials; in that case only the last one is shown and the previous ones
  are not visible on the lot nor on the inventory. The module could be
  extended to keep all the Bills of Materials used for a lot.
