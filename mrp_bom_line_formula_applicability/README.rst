Compute the applicability of a Production Line using a formula defined
in the BoM Line.

**Table of contents**

.. contents::
   :local:

Configuration
=============

In any BoM line, fill the Applicability Formula field.

The following values are available:

- \`bom_line\`: the current BoM line,
- \`production\`: the production order being created,
- \`product\`: the Product of current BoM line,
- \`product_uom_qty\`: the quantity of the production order line,
- \`product_uom\`: the UoM of the Product of current BoM line,
- \`operation\`: the operation where the components are consumed for
  current BoM line,

The 'applicable' variable must be assigned with True or False.

Usage
=====

This module can be used to determine the applicability of a component in
a production order based on a formula defined in the BOM that depends on
factors such as the product, BOM, or the production order itself.
