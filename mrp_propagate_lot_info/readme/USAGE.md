To use lot propagation in manufacturing:

1. Confirm the manufacturing order.
2. Consume exactly one lot/serial number for the configured component.
3. Set the finished product lot/serial number.
4. Validate the manufacturing order.

During validation, the configured non-empty values from the consumed component
lot are copied to the finished product lot and to the lots of by-products that
have **Propagate Lot Info** enabled on the BoM.
