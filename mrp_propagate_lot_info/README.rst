Propagates selected stock lot fields from a consumed component to the
produced lots of a manufacturing order, including flagged by-products.

**Table of contents**

.. contents::
   :local:

Use Cases / Context
===================

Some manufacturing flows need produced lots to keep information from the
lot consumed for a key component.

For example, a component lot can define expiration or traceability
metadata that must remain available on the finished product lot, or on
selected by-product lots, after production.

The same need can appear on manual manufacturing orders that do not use
a BoM. In that case, the manufactured product category can define which
propagation profile should be used.

Configuration
=============

Only one component line can have a propagation profile per BoM, and the
component must be tracked by lots or serial numbers.

Propagated fields are grouped in profiles. To create one:

1. Go to **Manufacturing > Configuration > Lot Info Propagation
   Profiles**.
2. Create a profile.
3. Select the stock lot fields that the profile should propagate.

To configure product category defaults:

1. Go to a product category.
2. Set **MRP Lot Propagation Profile**.

That profile will be proposed automatically on BoM lines when selecting
a component from that category.

To configure a BoM:

1. Open the BoM.
2. On the component line that should provide the lot information, review
   or edit the lot propagation profile.
3. Leave the profile empty on the other component lines.
4. On by-product lines that should receive the same lot information,
   enable **Propagate Lot Info**.

For manufacturing orders created without a BoM, configure the
propagation profile on the manufactured product category. The order must
consume exactly one lot/serial number across all raw material moves.

Usage
=====

To use lot propagation in manufacturing:

1. Confirm the manufacturing order.
2. Consume exactly one lot/serial number for the configured component.
3. Set the finished product lot/serial number.
4. Validate the manufacturing order.

During validation, the configured non-empty values from the consumed
component lot are copied to the finished product lot and to the lots of
by-products that have **Propagate Lot Info** enabled on the BoM.
