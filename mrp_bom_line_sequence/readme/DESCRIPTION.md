Odoo already lets you reorder the components of a bill of materials by
dragging them. This module also shows the position of each component as
a number in the components list, which can be edited to move the line.

Lines are always numbered 1, 2, 3, ... in their order, also when they
are created outside the form view (by code or import), where new lines
are added at the end of the bill of materials. Duplicating a bill of
materials keeps the numbering of its lines.
