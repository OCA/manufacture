To install this module, you need to:

1.  Ensure the module `mrp_workcenter_safety_symbol` (and its dependencies `mrp` and `base_iso7010`) are installed.
2.  Ensure at least one data module (e.g., `base_iso7010_data_mandatory`) is installed to provide symbols.
3.  Add this repository to your Odoo addons path.
4.  Install the module 'MRP Work Center Safety Symbol Specification' (`mrp_workcenter_safety_symbol_specification`).

Installing this module will automatically modify the view provided by `mrp_workcenter_safety_symbol`.
