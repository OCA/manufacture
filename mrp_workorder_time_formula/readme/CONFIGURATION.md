1. Open a **Bill of Materials** and go to the **Operations** tab.
2. On any operation line, set one or both of the new fields:
   - **Fixed Duration**: number of minutes always added to the work order,
     regardless of quantity (e.g. setup time).
   - **Cadence**: units produced per minute. Leave at `0` to ignore.
3. Save the BoM. The fields are also available on the standalone Operations
   form (`Manufacturing > Configuration > Operations`).
