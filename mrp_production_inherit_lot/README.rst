Use Cases / Context
===================

In some production environments, we need to produce extra products with
the same lot. This products will not be sold and we want them to inherit
the same lot than the original one.

Some examples would be in healthcare or food industries, where the
producer needs to keep a sample of each lot.

Usage
=====

Access a BOM and check the inherit lot field on byproducts.

When you produce using this BOM, when setting the lot, a lot with the
same name will be applied to this byproduct.
