To install this module, you need to:

1.  Ensure the base module `base_iso7010` is installed.
2.  Ensure the standard Odoo module `mrp` is installed.
3.  Install at least one data module (e.g., `base_iso7010_data_mandatory`) to have symbols available for selection.
4.  Add this repository to your Odoo addons path.
5.  Install the module 'MRP Work Center Safety Symbols' (`mrp_workcenter_safety_symbol`).
