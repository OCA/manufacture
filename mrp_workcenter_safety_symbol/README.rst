This module allows associating standard ISO 7010 safety symbols with
Manufacturing Work Centers in Odoo.

Overview
--------

This module provides the basic functionality to link predefined ISO 7010
safety symbols (managed via the ``base_iso7010`` module and populated by
``base_iso7010_data_*`` modules) to specific Manufacturing Work Centers
(``mrp.workcenter``).

Features:

-  Adds a 'Safety Symbols' tab to the Work Center form view.
-  Provides a Many2many field (``safety_symbol_ids``) to link
   ``mrp.workcenter`` records to ``iso7010.symbol`` records.
-  Displays selected symbols visually using a Kanban view within the
   tab.

Use Cases / Context
===================

In manufacturing settings, safety procedures are often tied to specific
locations, machines, or workstations (represented as "Work Centers" in
Odoo MRP). There is a business need to clearly associate standard safety
symbols (like required PPE or warnings) with the relevant Work Centers.
This allows for:

-  Quick visual reference for operators and supervisors.
-  Inclusion of relevant symbols in documentation like work instructions
   or travelers.
-  Foundation for safety checks or compliance tracking related to
   specific equipment.

*Example Use Case:* A metal press Work Center always requires "Wear Eye
Protection" (M004) and "Wear Hearing Protection" (M003). This module
allows linking these two symbols directly to the press's Work Center
record in Odoo.

Installation
============

To install this module, you need to:

1. Ensure the base module ``base_iso7010`` is installed.
2. Ensure the standard Odoo module ``mrp`` is installed.
3. Install at least one data module (e.g.,
   ``base_iso7010_data_mandatory``) to have symbols available for
   selection.
4. Add this repository to your Odoo addons path.
5. Install the module 'MRP Work Center Safety Symbols'
   (``mrp_workcenter_safety_symbol``).

Configuration
=============

This module requires no specific configuration after installation. Users
with appropriate permissions for Manufacturing configuration will be
able to edit Work Centers and use the added "Safety Symbols" tab.

Usage
=====

To associate safety symbols with a Work Center:

1.  Ensure you have installed the necessary ``base_iso7010_data_*``
    modules to load the symbols you want to use.
2.  Navigate to the Manufacturing app.
3.  Go to Configuration > Work Centers.
4.  Open the Work Center record you wish to configure or create a new
    one.
5.  Click on the "Safety Symbols" tab.
6.  You will see an area displaying currently selected symbols
    (initially empty) as small visual cards (Kanban view).
7.  Click "Add a line" (or similar text/button that appears). A modal
    window will appear.
8.  Select one or more safety symbols from the list. You can use the
    search bar to find symbols by name or code.
9.  Click "Select".
10. The selected symbols will appear as cards on the "Safety Symbols"
    tab.
11. To remove a symbol, you may need to open the selection modal again
    or use controls on the Kanban card.
12. Click "Save" on the Work Center form.

The selected symbols are now associated with this Work Center. This
module itself does not perform further actions based on these symbols.
