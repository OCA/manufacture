Installation
============

This module depends on ``base_tier_validation``. You can find it at
`OCA/server-ux <https://github.com/OCA/server-ux>`__

Configuration
=============

To configure this module, you need to:

1. Go to *Settings > Technical > Tier Validations > Tier Definition*.
2. Create as many tiers as you want for Production model.

Usage
=====

To use this module, you need to:

1. Create a Production triggering at least one "Tier Definition".
2. Click on *Request Validation* button.
3. Under the tab *Reviews* have a look to pending reviews and their
   statuses.
4. Once all reviews are validated click on *Validate*.

Additional features:

- You can filter the Production requesting your review through the
  filter *Needs my Review*.
- User with rights to validate the Production (validate all tiers that
  would be generated) can directly do the operation, this is, there is
  no need for her/him to request a validation.
