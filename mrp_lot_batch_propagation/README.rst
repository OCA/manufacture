This module adds functionality to track Bill of Materials (BOM)
information through manufacturing batches for quality control purposes.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Create a Manufacturing Order for a batch product using a specific
   BOM.
2. When the production is marked as done, the origin BOM is
   automatically stored on the finished lots.
3. Create subsequent Manufacturing Orders that consume these batch lots.
4. The subsequent Manufacturing Orders will display the origin BOMs from
   consumed batches as tag buttons.
