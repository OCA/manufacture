Once a work center has a resource calendar configured and "Use Calendar
for Time Tracking Duration" enabled, no further action is needed: the
Duration shown in the work order's "Time Tracking" tab is computed
automatically from that calendar.

Example: with a calendar that has a 12:00-13:00 lunch break, an activity
logged from 10:00 to 14:00 is counted as 3 hours instead of 4, since the
lunch hour is excluded automatically.
